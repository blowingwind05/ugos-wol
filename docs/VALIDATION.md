# 0.1.2 启用失败修复验证

日期：2026-11-11（Asia/Shanghai）。UPK：0.1.2.0001。

实际安装的 0.1.1 服务在约 74ms 后以退出码 2 失败。应用日志明确记录 `removed GODEBUG "tlskyber" set to old value "0" in environment`。检查确认 NAS systemd 管理器设置了 `GODEBUG=tlskyber=0`；后台二进制与原始交付文件 SHA256 相同。

本设备修复限定于 `com.local.wol.service`：以专属 systemd 配置清除该应用继承的旧参数，保留 NAS 全局设置。实际 UGOS 隔离环境下服务持续运行，静态页面 HTTP 200，缺少登录身份的 API 返回 401；用户文件、设备配置和发送记录均保留。

更新包使用官方 Go 1.26.11 编译。新增构建工具链固定和 `GODEBUG=tlskyber=0` 条件下的回归检查，避免以后用不兼容工具链重建。

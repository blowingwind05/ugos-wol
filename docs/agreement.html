许可与使用条件

项目源码按仓库 LICENSE 公布的 MIT 许可分发，第三方组件各自保留其许可和署名。本协议不会限制对应开源许可已经授予的权利。应用当前免费提供，不包含订阅或内购。

请仅管理你拥有或获准管理的设备。目标设备、固件、网卡驱动、电源状态与网络需支持 WOL；“已发送”只代表 NAS 发出了数据包，不能保证设备启动或远程连接成功。状态检测有响应也不代表登录或串流服务已就绪。

定时任务与数据

启用任务后，NAS 将在对应时区按计划发包，即使页面已关闭。工作日为周一至周五，周末为周六、周日，不自动调整节假日。NAS 或应用停用期间错过的执行会跳过。请保存适当备份，重要操作前核对设备与时区。

卸载会清理本应用的数据目录。修改、删除设备或任务前，请考虑同一 NAS 上其他管理员的使用。关于信息处理和用户权利，见独立隐私政策。

支持与问题反馈

通过 GitHub Issues 或 联系邮箱反馈问题。请提供应用版本、CPU 架构、UGOS 版本、访问端和错误信息，并对截图、日志中的个人信息作遮盖。请勿在公开问题中上传密码或令牌。

责任与适用规则

开发者在适用法律及开源许可允许的范围内提供应用；依法不能排除或限制的责任和用户权利不受本协议影响。如对本协议有疑问，请先通过支持渠道沟通。
